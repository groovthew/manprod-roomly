## 🗺️ Halaman & Route

| Route                  | Akses        | Deskripsi                                            |
|------------------------|--------------|------------------------------------------------------|
| `/`                    | Public       | 🏠 Home — hero, services grid, features              |
| `/login`               | Public       | 🔐 Login / Register (toggle)                          |
| `/profile`             | Logged-in    | 👤 Edit profil + ganti password                       |
| `/laundry`             | Customer     | 🧺 Booking Laundry — carousel + form                  |
| `/cleaning`            | Customer     | 🧹 Booking Cleaning — carousel + time slots           |
| `/payment/:id`         | Customer     | 💳 Pilih metode pembayaran                            |
| `/my-bookings`         | Customer     | 📋 Daftar pesanan + filter                            |
| `/tracking/:id`        | Logged-in    | 📍 Live tracking detail + timeline                    |
| `/admin`               | Admin only   | 🛡️ Dashboard — kelola semua booking                  |
| `/admin/chat`          | Admin only   | 💬 Inbox chat customer + reply                        |

> 💬 **FloatingChat** mengambang di **semua halaman** untuk customer yang sudah login.

## 🚀 Cara Menjalankan Lokal

### Opsi A — Frontend saja (recommended, mode offline localStorage)

```bash
cd frontend
npm install
npm run dev
```

➡️ Buka [`http://localhost:5173`](http://localhost:5173)

### Opsi B — Frontend + Backend Express (untuk pengembangan lanjutan)

```bash
# Terminal 1
cd backend
npm install
npm run dev          # http://localhost:3001

# Terminal 2
cd frontend
npm install
npm run dev          # http://localhost:5173
```

> Vite akan proxy `/api/*` ke backend secara otomatis.

## ☁️ Deploy ke Vercel

<details>
<summary><b>📘 Panduan singkat (klik untuk expand)</b></summary>

1. Push repo ke GitHub
2. Buka [vercel.com](https://vercel.com) → **Import Project** → pilih repo
3. Set **Root Directory**: `frontend`
4. **Framework Preset**: Vite (auto-detect)
5. **Deploy** — selesai! Update otomatis tiap `git push`

</details>
